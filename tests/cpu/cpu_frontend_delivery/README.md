# Isolated Step5A registered target delivery

One writeback overlay on exact passing4G; no production changes. Registered CPU
targets enter the first ready PC stage directly; inactive address payloads keep
the target for private resident lookahead while valid remains clear. No new state.

adds read-only I-cache attribution. `jpeg.py` reuses the established first Thumb

writeback target/state/priority checks. Store-stream and diagnostic helpers reuse
