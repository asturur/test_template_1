the input for multicorner constrained sign-off.

`Equal0~0_OTERM161` and end at diagnostic telemetry snapshot RAM data-input
registers `porta_datain_reg8` and `porta_datain_reg2`. The worst has 12 logic
levels and 12.422 ns reported data delay. This identifies the **diagnostic
snapshot capture path** as the immediate timing target. No RTL fix was applied.

The reported SDRAM falling-capture-to-adapter paths have **+3.815 ns** worst
setup margin (10 sampled paths). Controller paths in the global endpoint
subset have +0.977 ns worst margin. The dedicated capture-to-capture pattern
returns `no_paths`; that diagnostic is not counted as a passing measurement.
The two negative endpoints shown here are not in the native SDRAM command or
CPU arithmetic execution paths.

filter/clock warnings are also present. Internal passing domains do not certify
